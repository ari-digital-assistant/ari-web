# Getting started

Ari is an open-source, on-device digital assistant. Today that means Android
— a desktop app is on the way, but hasn't landed yet.

## Installing Ari

Ari is pre-release, so it isn't in an app store yet. The way to get it is
from [GitHub releases](https://github.com/ari-digital-assistant) — grab the
latest APK and install it. F-Droid and Play Store listings are coming soon,
for anyone who'd rather update through a store.

There's no account to create and no sign-up screen. Install the app and
you're in.

## First run

The first time you open Ari, an onboarding wizard walks you through the
handful of things it needs:

- **Microphone permission.** Ari needs this to hear you — without it, voice
  input won't work (typing still will).
- **A wake word.** Pick the phrase Ari listens for, such as "Hey Ari" or "Ok
  Ari". You can change this later in Settings.
- **The on-device brain.** Optionally download the on-device language model
  so Ari can answer open-ended questions without needing the internet.

## Talking to Ari

There are three ways to get Ari's attention:

- Say the wake word, then ask your question.
- Tap to talk, if you'd rather not say the wake word out loud.
- Type your question directly.

Ari replies with spoken answers, and often a card on screen with more detail
— the two work together, so you can glance or listen, whichever suits the
moment.
